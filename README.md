# 🏋️ FitZone — Fitness & Gym Management Platform

## 📌 Project Overview

FitZone is a modern Fitness & Gym Management Platform where users can explore fitness classes, book sessions, save favorites, join community discussions, and track their fitness journey.

The platform supports three different roles:

* **User**
* **Trainer**
* **Admin**

Each role has its own dashboard and functionalities.
